/speckit.specify

Project foundation for DashCraft. A developer can clone the repository, start
the whole system locally with one command, and see a working but empty
application: a web app that loads in the browser, an API that responds to a
health check, and a database that is connected and ready. The backend and
frontend each have a working automated test setup with one passing sample test,
and integration tests run against a real SQL Server instance. The repository
follows the structure defined in the constitution, and the README explains how
to run the system and the tests. No product features (connections, dashboards,
queries, authentication) are part of this feature.
